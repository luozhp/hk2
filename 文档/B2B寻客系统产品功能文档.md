## 2. 产品概述

### 2.1 背景与问题

公司主营 N₂O cream charger（奶油气弹）与 cream whipper（奶油枪），面向美国 B2B 市场（餐饮分销商、进口批发商、贴牌品牌、电商批发商）。获客策略分为**被动获客**（SEO、广告、B2B 平台）与**主动开发**（Google 搜索、LinkedIn、海关数据、黄页、展会）两条线。

**现存问题**：

1. 线索分散在各业务员 Excel、邮箱、微信中，无统一沉淀；
2. 主动开发流程（搜索 → 筛选 → 找人 → 发信 → 跟进）完全靠人工记忆，易漏单；
3. 合规要求高（危险品、禁词、认证文件），人工易出错；
4. 投放、SEO、邮件效果无数据闭环，无法量化投入产出；
5. 没有基于 KPI 的目标管理与跟进预警机制。

### 2.2 产品定位

> 面向外贸业务团队的 **B2B 寻客与客户开发一体化工作台**，把"找客户 → 筛客户 → 管客户 → 触达客户 → 成交转化"全流程数字化，实现被动获客与主动开发双引擎的可视化运营。

### 2.3 产品目标与成功指标

| 维度 | 指标 | 2026 目标 | 2028 目标 |
|---|---|---|---|
| 线索 | 沉淀有效线索数 | ≥ 500 条 | ≥ 3000 条 |
| 询盘 | 独立站+平台询盘量 | ≥ 100 条/年 | ≥ 500 条/年 |
| 邮件 | 开发信回复率 | ≥ 3%（行业基准 3-8%） | ≥ 5% |
| 成交 | 活跃客户数 | ≥ 5 家 | ≥ 20 家 |
| 效率 | 业务员日均主动开发效率 | 提升 50% | 提升 100% |

### 2.4 用户角色与使用场景

| 角色 | 说明 | 核心诉求 |
|---|---|---|
| 业务员 | 外贸销售，负责主动开发与跟进 | 快速找到高质量线索、发信、跟进不遗漏 |
| 运营专员 | 负责 SEO、广告、内容、平台 | 关键词/广告/内容管理，数据看板 |
| 管理者 | 老板/销售主管 | 团队进度、KPI、目标达成、线索分配 |

### 2.5 术语表

| 术语 | 定义 |
|---|---|
| 线索（Lead） | 未经确认的需求方公司信息（含来源渠道） |
| 客户（Customer） | 已验证有效、可跟进的公司 |
| 联系人（Contact） | 客户内部决策人（采购/进口/品类经理、老板） |
| 商机（Opportunity） | 有明确采购意向的销售阶段（询盘→样品→报价→成交） |
| 合规文档 | MSDS、UN/DOT 认证、食品级资质等文件 |
| 禁词 | recreational / whip gas 等红线词汇 |

└─────────────────────────────────────────────────────────────┘

### 3.2 核心业务流程

**流程一：主动开发主流程**

```
Google搜索/黄页/海关数据/展会名录 → 线索采集
  → 三标准校验+评分去重 → 转为客户档案
  → 关联决策人(LinkedIn) → 合规资料自动附随
  → 开发信发送(个性化) → 回复跟踪 → 询盘/商机
  → 样品/报价 → 成交 → 复购管理
```

**流程二：被动获客主流程**

```
SEO内容/广告/平台 → 独立站落地页 → 询盘进入系统
  → 询盘自动查重 → 分配业务员 → 快速响应(24h)
  → 纳入客户档案 → 转化跟踪
```

**流程三：合规兜底流程**

```
所有对外内容(邮件/落地页/广告) → 禁词扫描 → 合规文档配置校验
  → 通过才可发送/发布 → 违规拦截并告警
```

- 线索唯一键：`domain`（域名查重）；客户唯一键：`domain` + `name`；

- 商机阶段变更必须写入时间线。

## 6. 页面清单与核心交互

### 6.1 页面清单

| 模块 | 页面 | 说明 |
|---|---|---|
| 工作台 | 首页 Dashboard | 今日任务、待跟进、未读回复、目标进度 |
| 线索 | 线索池列表 / 线索详情 / 线索采集（搜索页） / 数据导入 | 筛选器、批量操作、一键转客户 |
| 客户 | 客户列表 / 客户详情（时间线） / 客户地图 / 联系人列表 | 分级、标签、商机流转 |
| 邮件 | 模板库 / 发送中心 / 发送记录 / 回复收件箱 | 变量预览、频控状态、禁词拦截提示 |
| 合规 | 文档库 / 禁词库 / 检查清单 / 扫描报告 | 过期提醒 |
| 内容 | 关键词库 / 否定词库 / 落地页 / SEO 任务板 | 排名趋势（V2） |

| 询盘 | 询盘中心 / 分配规则 | SLA 计时 |
| 数据 | 驾驶舱 / 漏斗分析 / 渠道分析 / 绩效排行 | 导出报表 |
| 系统 | 用户管理 / 集成配置 / 审计日志 / 通知设置 | 角色权限 |

### 6.2 关键交互说明

1. **采集 → 校验 → 转客户一体化**：在"线索采集"页执行搜索 → 结果列表勾选 → 点击"校验并入库"，系统自动跑三标准校验并显示通过率，校验通过的标记"待转客户"，一键批量转为客户档案。
2. **发信三步曲**：选择客户/联系人 → 选择模板（变量自动预览） → 发送前自动执行"禁词扫描 + 合规文档检查 + 频控检查"，任一不通过即阻断并高亮问题位置。
3. **客户时间线**：客户详情默认展示时间线视图，邮件收发、电话、备注、商机变更全部按时间轴展示，支持按类型过滤。
4. **目标进度环**：驾驶舱顶部展示 2026 询盘目标与 2028 客户目标进度环，点击可下钻查看贡献明细。

## 10. 风险与依赖

| 风险/依赖 | 说明 | 应对 |
|---|---|---|
| Google 搜索结果合规 | 批量抓取可能触发反爬 | 使用官方 Search API 或人工辅助采集，控制频次 |
| 邮件进垃圾箱 | 影响触达率与发件域名信誉 | 频控、个性化、域名预热、SPF/DKIM 配置 |
| 禁词/合规红线 | 违反平台政策导致封号 | 全链路禁词扫描 + 合规检查清单兜底 |
| 海关数据成本 | 工具订阅几百~上千美元/月 | 一期用导入方式支持，预算确认后再 API 对接 |
| 账号集成授权 | Google/LinkedIn 授权需合规申请 | 立项时确认应用类型与权限范围 |
| 数据质量 | 线索数据含噪声 | 三标准校验 + 评分 + 黑名单机制持续净化 |
